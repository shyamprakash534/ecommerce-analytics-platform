# E-Commerce Sales, Customer & Profitability Analytics Platform

Portfolio-grade analytics dashboard for interactive e-commerce performance analysis.

## Live Application
Deployed on Render as a Streamlit web service.

## Features
- Executive Overview
- Sales & Profitability
- Customer Analytics
- Product & Category
- Regional Performance
- Interactive region, category, segment and date filters
- Revenue, profit, margin, discount and leakage KPIs
- Customer segmentation and spend analysis
- Product and regional profitability diagnostics

## Stack
Python, Pandas, NumPy, Plotly, Streamlit

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard generates a deterministic synthetic e-commerce dataset with NumPy seed 42 when started from a clean checkout.
